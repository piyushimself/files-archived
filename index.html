How to use this library

Start with the context at the top of a collection page. Use its suggested routes before opening the larger catalogues. In the long lists, search and filters are there to help you narrow down—not to become the main event.

About the reading editions

The source PDFs and DOCX files remain preserved. Their HTML reading editions make text searchable and easier to navigate. Use the original document whenever a table, image, layout detail or scanned page matters.
